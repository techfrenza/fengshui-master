# AI Skill：传统风水顾问

> 「峦头为体，理气为用；峦头差，理气无用；理气差，峦头吉地亦减分。」

一个遵循 [Agent Skills 开放标准](https://agentskills.io) 的 Skill，以江南三元世家传人的视角，运用玄空飞星、八宅明镜、择日学等传统方法，帮你分析居住环境、择吉日、化煞气。

只是一份 `SKILL.md` + 参考资料，可在 Claude Code、Codex CLI 等 30+ 兼容智能体中直接使用。

基于《沈氏玄空学》《地理五诀》《协纪辨方书》等传统典籍的系统性方法。

## 项目来源

本项目基于 [voidforall/fengshui.skill](https://github.com/voidforall/fengshui.skill) fork。原项目为初始框架，本版本进行了系统性的重大改进与扩展。

### 勘误与校正

经三元法理复核，本版修正了参考表中三处会导致排盘或断语出错的问题：

- **阴阳山向顺逆表（`feixing.md`）**：原「4 组合表」与主文法则相矛盾、顺逆方向写反，并列出「阳山配阴向」等实际不存在的组合。已改为沈氏正法——**阳顺阴逆，山星与向星各自独立判断**；并注明「上山下水／双星到向」是排盘结果、非顺逆输入条件。
- **反吟／伏吟定义（`feixing.md`）**：原「反吟」定义实为「合十」（山向和为 10，属吉象），吉凶颠倒。已改回「单盘逆飞与元旦盘对宫背离」，并加辨误说明；伏吟由「撞流年数」窄化说法改为「整盘复元旦盘位」。
- **男命卦基数分段（`wuxing-ganzhi.md`）**：原表未区分世纪，导致 2000 年后出生者算错一位。已补 1900–1999 用 `100−yy`、2000–2099 用 `99−yy` 两段；并修正尾数和为 5 的一行——男命应代**艮(8)**（原误作坤2）。

## 能做什么

- 据房屋朝向与入住时间**排玄空飞星盘**，判旺位凶位
- 据居住者命卦**配八宅游年**，给四吉四凶方布局
- 结合年月神煞**筛选入宅/开业/动土吉日**
- 识别路冲、天斩、壁刀等**外煞**并给化解
- **解读术语与经典原文**，答理论问题
