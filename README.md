# 玄学术数技能库 · 赛博算命

一个面向 [Agent Skills 开放标准](https://agentskills.io) 的中华玄学与术数知识技能库。每个技能都独立自洽，收录于 `skills/<name>/` 目录下，可被兼容的 AI Agent 加载调用。

> 传统术数，现代表达。以经典典籍为体，以脚本排盘为用；固定计算交给脚本，解读与建议交给 AI。

## 设计理念

- **脚本排盘，禁止口算** — 凡固定计算（排盘、抽牌）均由 Python 脚本完成，脚本 stdout 为权威结果，AI 不得覆盖。适用于 `bazi`、`qimen-dunjia`、`tarot`。
- **主权归用户** — 术数是自我观察与决策辅助的工具，不宣判固定命运。结尾提醒用户：当下能量可读，未来选择随时可以改变走向。
- **典籍为据** — 解读参照经典命理典籍，而非凭空发挥；参考资料仅为查表用途，方法论与人格设定统一收录于各技能的 `SKILL.md`。

## 目录结构

每个技能目录遵循统一布局：

```
skills/<name>/
  SKILL.md          # 权威文件：YAML frontmatter + 人格设定 + 工作流程
  README.md         # 人类可读概览（可选）
  references/       # 查表资料 — 仅表格，无叙述、无人格语气
  examples/         # 对话示例（仅 fengshui-master）
  scripts/          # Python 脚本（排盘/抽牌：bazi、qimen-dunjia、tarot；校验辅助：ziwei-doushu）
```

## 使用方式

本仓库无顶层构建系统。每个 `SKILL.md` 含合法的 YAML frontmatter（`name`、`description` 触发词列表，可选 `metadata`），由兼容的 Agent 运行时读取。`description` 中的触发词是技能的发现入口 —— 用户提及相关词汇（如「算八字」「看风水」「排紫微」「奇门」「合婚」「塔罗」等）时，Agent 会自动加载对应技能。

含 Python 脚本的技能可用 `python3` 直接运行；`qimen-dunjia` 需要 Python 3.11+、`lunar_python` 与 `tzdata`。
